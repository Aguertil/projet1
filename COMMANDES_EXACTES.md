## Étape 1: Créer le Repository GitHub

**Ouvrez ce lien dans votre navigateur:**

```
https://github.com/new
```

- Repository name: `screenapi`
- Public
- Cliquez "Create repository"

## Étape 2: Pousser le Code (Copier-Coller ces 2 lignes)

**Dans le terminal Cursor, copiez-collez:**

```bash
git remote add github https://github.com/mohamed-baabouz/screenapi.git
```

Puis:

```bash
git push github main
```

## Étape 3: Déployer sur Heroku (1 clic)

**Ouvrez ce lien dans votre navigateur:**

```
https://heroku.com/deploy?template=https://github.com/mohamed-baabouz/screenapi
```

**OU utilisez Railway (plus simple):**

```
https://railway.app/new/template?template=https://github.com/mohamed-baabouz/screenapi
```
